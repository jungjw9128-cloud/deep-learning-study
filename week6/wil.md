인공지능 모델은 입력을 받아 출력으로 변환하는 하나의 함수이다. 퍼셉트론은 입력에 가중치를 곱하고 편향을 더 하는 구조로 구성되어 있고 여러 퍼셉트론을 연결하여 복잡한 신경망을 구성한다. 학습은 함수의 parameter인 가중치와 편향을 조절하여 적절한 출력을 생성하도록 하는 과정이다. 과적합이 발생하면 L1, L2 regularization과 dropout을 이용해 일반화 성능을 높인다. 이미지의 경우 가까운 픽셀들이 관련되어 있으므로 작은 kernel로 국소적인 특징을 추출하고 convolution으로 feature map을 생성하고 pooling으로 크기를 줄인다. ResNet은 입력 x에 F(x)를 더하는 구조를 통해 깊이가 증가할수록 학습 성능이 저하되는 문제를 해결할 수 있습니다. LSTM과 GRU는 gate를 통해 RNN의 장기 의존성 문제를 완화한다. self-attention은 입력으로부터 query, key, value를 생성하고 query와 key의 내적점수에 softmax를 적용해 참조 비율을 계산한다. 이후 해당 비율로 value를 가중합하여 각 토큰의 문맥 표현을 생성한다. multi-head attention에서는 서로 다른 가중치로 여러 패턴을 계산한 후 이를 결합한다.
