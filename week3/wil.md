RGB이미지가 입력일 때, 28*28*3이 된다. 3은 RGB채널이다.이 이미지에 Conv2D(16, 3, padding="same")을 적용한다고 했을 때, R채널, G채널, B채널에 각각 3*3 filter을 적용한다. 16개의 층을 쌓는 것이 아닌 3*3*3 filter를 적용해서 16개의 feature map을 만드는 것이다. Conv2D(16, 3, padding="same")을 반복하여 Layer를 쌓는다. Conv2D에서 ReLU를 적용하는 이유는 ReLU를 적용하지 않으면 아무리 층을 깊게 쌓아도 전체 네트워크는 하나의 거대한 선형 함수처럼 되서 복잡한 데이터 패턴을 학습할 수 없기 때문에 ReLU를 적용해 비선형성을 만들어 낸다. ReLU를 적용하면 비선형성이 만들어지는 이유는 양수일 때와 음수일 때 다른 규칙을 적용해서 f(x+y)= f(x)+f(y)인 선형성을 만족하지 않기 때문이다. filter 개수, kernel크기, stride는 직접 설정하는 hyperparameter이고, filter 내부의 값들은 학습되는 parameter이다.
